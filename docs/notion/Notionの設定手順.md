# Notion「口コミアプリ ヒアリング台帳」の作り方

流れ:

```
お客様がフォームに回答
   ↓（Notionの台帳に1行ふえる）
「Claudeへの指示」の欄に、回答が入ったプロンプトが自動でできる
   ↓
スタッフがそれをコピーして、Claude（Code タブ・moveact-kuchikomi フォルダ）に貼る
   ↓
Claude が tenants/<slug>.json を作り、手元で画面を作って確認表とスクリーンショットを出す
   ↓
三上様の承諾 → 本番登録 → 夜間にドメインを足して反映
```

作るのは最初の1回だけで、10分ほどかかります。

## 1. 台帳を取り込む

1. Notion で、台帳を置きたいページを開く
2. 右上の「…」→「インポート」→「CSV」で、`docs/notion/口コミアプリ_ヒアリング台帳.csv` を選ぶ
3. 名前を「口コミアプリ ヒアリング台帳」にする

## 2. 列の種類を変える

取り込んだ直後は、どの列も「テキスト」になっています。次の列だけ、種類を変えてください（列名をクリック →「プロパティの種類」）。

| 列 | 種類 | 選択肢 |
|---|---|---|
| ステータス | セレクト | 受付／作成中／確認待ち／公開／保留 |
| メールアドレス | メール | |
| 電話番号 | 電話 | |
| 業種 | セレクト | 整骨院・接骨院／整体院／鍼灸院／ピラティス・ヨガ／フィットネス／美容室／エステ・脱毛／ネイル・まつげ／歯科／飲食店／その他 |
| 受けるものの呼び方 | セレクト | 施術／レッスン／施術・レッスン／カット・カラー／トリートメント／治療／その他 |
| 店内の呼び方 | セレクト | 店内／院内／スタジオ／サロン／その他 |
| 担当者の呼び方 | セレクト | 施術者／スタッフ／インストラクター／トレーナー／スタイリスト／セラピスト／先生／その他 |
| 来店頻度の呼び方 | セレクト | 通院頻度／来店頻度／利用頻度 |
| 口コミの特典・指示をしないことへの同意 | チェックボックス | |
| アプリのURL | URL | |

さらに、次の列を新しく足します。

| 列 | 種類 |
|---|---|
| ロゴ画像 | ファイルとメディア |
| 担当スタッフ | ユーザー |
| Claudeへの指示 | 数式 |

## 3. 「Claudeへの指示」の式を入れる

「Claudeへの指示」列の数式の編集画面を開きます。`docs/notion/Claudeへの指示_式.txt` の中身を**全部コピーして貼り付け**、「完了」を押します。

式の中では、列名で値を読んでいます。**列名を変えると式が動かなくなるので、列名は変えないでください。**

## 4. お客様用のフォームを作る

1. 台帳の右上「＋」（ビューを追加）→「フォーム」
2. 次の質問を、この順に並べる。「必須」が付いたものは必須にする

| 質問（列） | 必須 | フォームに出す説明文 |
|---|---|---|
| 店舗名 | 必須 | 画面の一番上に大きく出る名前です |
| ご担当者名 | 必須 | |
| メールアドレス | 必須 | |
| 電話番号 | | |
| 業種 | 必須 | |
| 業種（その他の内容） | | 「その他」を選んだ方だけ |
| 店舗一覧 | 必須 | 1行に1店舗ずつ「店舗名／住所／地域名」。例：さくら整骨院／岡山県倉敷市玉島1-2-3／倉敷市玉島 |
| GoogleマップのクチコミURL | 必須 | 店舗ごとに1行ずつ。Googleビジネスプロフィールの「クチコミを増やす」で出るURLです |
| メニュー | 必須 | 1行に1つ「メニュー名／ひとこと説明」。実際に提供しているものだけを書いてください |
| 来店目的・お悩み | 必須 | お客様がよく来られる目的を、1行に1つ。例：肩こり・首こり |
| スタッフの強み | | 1行に1つ。例：丁寧な説明 |
| お店の良いところ | | 1行に1つ。例：駐車場が広い |
| 受けるものの呼び方 | 必須 | |
| 店内の呼び方 | 必須 | |
| 担当者の呼び方 | 必須 | |
| 来店頻度の呼び方 | 必須 | |
| ブランドカラー | | 色の番号（例：#2a2960）か、言葉（例：落ち着いた紺色） |
| ロゴ画像 | | |
| 希望のアドレス名 | | 英字で。例：sakura → sakura.kuchikomi.s-toru.com |
| 口コミの特典・指示をしないことへの同意 | 必須 | 「口コミを書いていただく見返りに、割引・特典を出さないこと、書く内容をお店から指示しないことに同意します」 |

ステータス・独自ドメイン・月次レポートの送り先コード・アプリのURL・担当スタッフ・Claudeへの指示は、**フォームに出さない**でください（社内用の欄です）。

3. フォームの設定で「誰でも回答できる」にして、リンクをコピーする。このリンクを、お申し込みのあったお客様に送ります

同意のチェックは、ステマ規制への対応のために必須にしています。外さないでください。

## 5. スタッフの使い方

1. 回答が届いたら、台帳の「ステータス」を「作成中」にする
2. その行を開き、「Claudeへの指示」の中身を**全部コピー**する
3. Claude デスクトップアプリの **Code タブ**で、`CODE/moveact-kuchikomi` フォルダの会話を開いて貼り付ける
4. Claude が作業し、最後に確認表とスクリーンショットを出す。回答と違う所があれば、その場で Claude に伝えて直してもらう
5. 「ステータス」を「確認待ち」にして、三上様に確認表を見ていただく
6. 三上様の承諾のあとの本番登録・夜間の反映も、Claude に「三上様の承諾が出たので本番に出して」と伝えれば進めます
7. 公開できたら「ステータス」を「公開」にし、「アプリのURL」を入れる

Claude が「同意が取れていない」「メニューが足りない」と止まったときは、お客様に確認してから回答を直し、もう一度コピーし直して貼ってください。
